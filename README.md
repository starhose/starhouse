# STAR HOUSE

Официальный сайт проекта **STAR HOUSE**.

## О проекте

STAR HOUSE — это команда, которая создаёт контент, рисует и снимает видео. Сайт — официальная площадка проекта: здесь публикуются новости, услуги и ссылки.

## Что есть на сайте

- **Главная** — приветствие и анимированный логотип
- **Услуги** — Аватарка (100 ₽), Обложка (100 ₽), Совместное видео (50 ₽)
- **Публикации и новости** — актуальные новости проекта
- **Подписка** — ссылка на TikTok
